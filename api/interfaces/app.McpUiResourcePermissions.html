    Interface McpUiResourcePermissions

    Description

    Sandbox permissions requested by the UI resource.

    Servers declare which browser capabilities their UI needs. Hosts MAY honor these by setting appropriate iframe allow attributes. Apps SHOULD NOT assume permissions are granted; use JS feature detection as fallback.
